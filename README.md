----------------  Project Title: MCQ answer key generator -----------------------


-   answer_table.sql — creates the tables (student, answer_table, op_table) and loads sample student answers

-   answers.awk — reads a raw answer-key text file and prints INSERT INTO answer_table statements

-   data.txt — example input file, in the format the awk script expects

-   insert.sql is the insert statement generated by running the awk script on data.txt 
-----  How to run -----------

awk -f answers.awk data.txt > insert.sql

.read answer_table.sql

.read insert.sql
